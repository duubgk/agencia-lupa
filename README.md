# Agência Lupa

Jogo de detetive no navegador Desenvolvido com apoio do Claude (Anthropic). Cada caso traz suspeitos, pistas e documentos, e o jogador precisa cruzar as informações para descobrir o culpado.

**Jogar:** https://duubgk.github.io/agencia-lupa/

## Como funciona
- 5 casos com dificuldade crescente: roubo, fraude e troca de joia.
- Os casos 4 e 5 não têm depoimentos, só prints de conversa, registros e documentos.
- Pistas com ampliação, bloco de notas e acusação final.
- O jogo só avisa se a acusação está certa ou errada. Dicas só aparecem se o jogador pedir.
- O progresso fica salvo no navegador de cada jogador.

## Tecnologias
HTML, CSS e JavaScript em um único arquivo (index.html), com ilustrações em SVG. Publicado com GitHub Pages.
